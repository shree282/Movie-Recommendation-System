# Movie Recommendation System

## About
This project recommends movies based on their genres using Machine Learning.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit

## How It Works
1. Load the movie dataset.
2. Process the movie genres.
3. Use TF-IDF to convert genres into numbers.
4. Use Cosine Similarity to find similar movies.
5. Display the top recommended movies.
